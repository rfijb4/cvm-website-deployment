## 腾讯云建站教程的两条主线：镜像部署和手动搭建差在哪

镜像部署是用腾讯云云市场里的系统镜像直接装好现成网站系统，手动搭建则是自己装 Web 服务器、数据库和 PHP 之类的软件。前者点几下就能用，后者要自己处理版本兼容，但能装官方镜像里没有的系统。

腾讯云官方给的对比是这样的：

| 对比项 | 镜像部署 | 手动搭建 |
| --- | --- | --- |
| 搭建方式 | 选择云市场中的系统镜像直接安装部署 | 手动安装所需软件，可定制 |
| 软件版本 | 相对固定 | 可以灵活选择 |
| 所需时间 | 比较短，一键部署 | 比较长，需自行安装 |
| 难易程度 | 相对简单 | 需要对软件版本和安装方法有了解 |

除了 CVM，腾讯云还有轻量应用服务器（Lighthouse）的“一键建站”：创建实例时选应用镜像，不用自己配环境。个人站和小型官网用它足够，代价是可调整的空间比 CVM 小。

判断标准很简单：完全不想碰命令行，走镜像部署或 Lighthouse；要指定软件版本、要改 Nginx 配置、要装镜像里没有的系统，走手动搭建。

## 镜像建站实操：从买服务器到网站上线

以云官网AI建站为例，完整流程是：购买带建站镜像的云服务器 → 配安全组放行端口 → 激活网站 → 装模板或 AI 生成页面 → 预览并发布 → 绑定域名、备案。云市场里还有其他建站镜像，激活方式各不相同，但购买、端口、备案这几步是共通的。

### 第一步：买一台带建站镜像的 CVM

云官网建站官方推荐的起步配置是 CentOS 7.9 64 位、2 核 2G、3M 带宽。活动页上的服务器规格是蜂驰型 BF1 2 核 2G 3M 带宽，CPU、磁盘和带宽可以单独升配，参考承载量是日均 1500 个访问 IP。

节点可选广州、上海、北京、南京、香港、新加坡、首尔、法兰克福、硅谷。这个选择会直接影响后面的流程：境内节点必须做 ICP 备案，香港和境外节点不需要。

### 第二步：安全组放行端口

这一步最容易被跳过，也是“网站发布不了”的高频原因。云官网建站需要放行的端口：

- 21：网站 FTP 发布端口，来源 0.0.0.0/0
- 80、443：网站访问
- 5000-6000：网站被动发布端口，来源 202.91.0.0/16

用快速购买（推荐一）下单，安全组默认全部放行，可以跳过这步；出于安全考虑，官方建议改成只保留 21、80、443 和 5000-6000。自定义购买则要进控制台 → 安全组 → 入站规则 → 编辑规则，手动补上 21 和 5000-6000 两段。80 和 443 如果在新建安全组时勾了默认端口，通常已经开着。

> 端口或来源地址填得和文档不一致，网站部署完会卡在发布环节。按表格原样填，别自己改来源段。

### 第三步：激活网站后台

浏览器打开 `http://公网IP/wdsadmin`，按提示授权登录。激活要填两样东西：腾讯云账号 ID 和云官网建站的镜像订单编号，分别在账号基本信息页和订单管理页复制。

有个限制得先说清楚：授权账号必须和购买 CVM 的账号是同一个，子账号和协作者账号都不行。用公司账号买的服务器，就让主账号的人来激活。

激活成功后点底部的“马上建站”，进网站后台。

### 第四步：模板、栏目和内容

后台路径是 建站管理 → 更换模板，可以按行业或关键词搜模板，点安装。所有模板都能免费安装，也可以直接用 AI 生成整站。

接着在“网站编辑”里搭结构：

- 添加新栏目：填栏目名称和栏目文件名
- 添加区域布局：选空白区域或现成的区域样式
- 添加模块：从左侧工具栏拖到页面对应位置
- 产品管理、文章管理：先建分类，再上传内容

模块支持右键复制、删除、粘贴，也支持 Ctrl+C、Ctrl+V、Ctrl+Z、Ctrl+S。

### 第五步：预览、发布、上线

右上角“预览”能生成预览地址，确认没问题再点“发布”。发布进度到 100% 后，如果 80 端口开着，直接用 IP 就能访问真实网站。之后每次改内容都要重新点一次发布，数据才会同步到云服务器。

## 手动搭建路线：WordPress、Discuz!、LNMP、LAMP、Ghost 分别适合谁

手动搭建适合有 Linux 基础、要指定软件版本或要装镜像里没有的系统的人。腾讯云为几个主流系统都准备了对应文档，选择逻辑大致是这样：

- WordPress：PHP + MySQL 的博客平台，也能当 CMS 用，Linux 和 Windows 都有教程，个人站和企业站最常见
- Discuz!：PHP + MySQL 的论坛系统，适合做社区
- LNMP：Linux + Nginx + MySQL/MariaDB + PHP，既有镜像部署版，也有 CentOS 7 下手动搭建的文档
- LAMP：把 Nginx 换成 Apache 的同类架构
- Ghost：基于 Node.js 的开源博客，部署快，适合纯写作
- Microsoft SharePoint 2016：企业门户，适合需要内部协作站点的组织

只写博客，WordPress 或 Ghost 就够；做论坛选 Discuz!；手上是 PHP 应用，按 Web 服务器偏好选 LNMP 或 LAMP。手动搭建的代价是要自己处理软件版本兼容和后续升级，这部分时间得算进去。

## 网站做好了却打不开？按这个顺序排查

发布之后打不开，多数情况出在备案、端口或发布状态上，按下面顺序查一遍基本能定位。

1. 备案：境内节点必须完成 ICP 备案，备案编号要挂在网站底部；香港和境外节点不需要。打算备案的话，买服务器时包年包月时长要大于 3 个月。
2. 端口：80 和 443 有没有放行；发布依赖的 21 和 5000-6000 是否按来源地址填对。
3. 发布状态：后台改了内容但没点“发布”，线上还是旧版本。
4. 域名解析：域名要注册、实名认证、解析到服务器 IP，外部才访问得到。
